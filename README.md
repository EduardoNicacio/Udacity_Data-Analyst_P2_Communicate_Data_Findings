# Project: Communicate Data Findings

## Check Before Submission

Use the classroom instructions to complete the project. Once you're done, refer to the [Project Rubric](https://review.udacity.com/#!/rubrics/3592/view) to check if your project meets **all** specifications.

## Submission

If you are ready to submit your project, make sure that you collect the following files in a .zip file:

1. A report with your **exploratory** data analysis in PDF or HTML format. You should also include the original `.ipynb` file in your submission.
2. A report with your **explanatory** analysis in PDF or HTML format. Again, include the original `.ipynb` file with your submission.
