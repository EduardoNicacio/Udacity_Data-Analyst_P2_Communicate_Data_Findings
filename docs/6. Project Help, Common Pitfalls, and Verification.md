# Project Help, Common Pitfalls, and Verification

## Task List

- [ ] The code should run without errors.
- [ ] The project uses functions, loops, comments and docstrings.
- [ ] Questions and observations are placed regularly throughout the report, after each plot, using the "Question-Visualization-Observations" framework.
- [ ] Visualizations use appropriate plot type, data encodings, transformations, and formatting (title, axis-labels) as needed.
- [ ] The explanatory notebook has at least 3 visualizations having key insights matching those documented in the exploratory phase.
- [ ] All plots in the explanatory notebook are appropriate (plot type, encosings, and transformations) and polished (chart title, x/y axis label with units, x/y ticks, and legend).
- [ ] Includes at least one histogram.
- [ ] Includes (atg minimum) a bar chart or count plot.
- [ ] Includes a scatter plot.
- [ ] Includes a box plot.
- [ ] Includes a clustered bar chart or heatmap.
- [ ] Includes at least one Facet Plot.
- [ ] Includes a plot matrix or scatterplot with multiple encodings.
- [ ] A summary HTML or PDF of both Exploratory and Explanatory notebooks is generated.
