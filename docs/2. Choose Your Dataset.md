# Choose Your Dataset

Below is a compiled list of the datasets you can choose from. However, you can explore other datasets that interest you.

> **Note**: If you work in the Udacity provided Jupyter notebook workspace, ensure that the total size of all your files, including the dataset, in the workspace must not exceed 1 GB.

## [Ford GoBike System Data](https://video.udacity-data.com/topher/2020/October/5f91cf38_201902-fordgobike-tripdata/201902-fordgobike-tripdata.csv) (38 MB, CSV File)

This data set includes information about individual rides made in a bike-sharing system covering the greater San Francisco Bay area.

## [Flights](https://www.transtats.bts.gov/DL_SelectFields.aspx?gnoyr_VQ=FGJ&QO_fu146_anzr=b0-gvzr)

If the original link above does not work, you can download the dataset from here: [airline_2m.tar.gz](https://video.udacity-data.com/topher/2023/December/6571fb88_airline_2m.tar/airline_2m.tar.gz). The size of the compressed file is 152 MB, and has 2 Million rows.

- The dataset name is "Reporting Carrier On-Time Performance Data." This dataset reports flights in the United States, including carriers, arrival and departure delays, and reasons for delays from 1987 to 2022. You can see the database description at the [Bureau of Transportation Statistics](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FGJ).
  - Note that this is a large dataset; there are > 100 million records in total, which takes up to 12 GiB storage space.
  - You may want to take a subset of the data (e.g., ten years) to explore.

## [Loan Data from Prosper](https://s3.amazonaws.com/udacity-hosted-downloads/ud651/prosperLoanData.csv) (82.5 MB, CSV File)

This data set contains 113,937 loans with 81 variables on each loan, including loan amount, borrower rate (or interest rate), current loan status, borrower income, and many others. See the data dictionary below to understand the dataset's variables.

- [Google sheet](https://www.google.com/url?q=https://docs.google.com/spreadsheet/ccc?key%3D0AllIqIyvWZdadDd5NTlqZ1pBMHlsUjdrOTZHaVBuSlE%26usp%3Dsharing&sa=D&ust=1554486256024000)
- [Excel sheet](https://video.udacity-data.com/topher/2023/December/6571fe24_prosper-loan-data-variable-definitions/prosper-loan-data-variable-definitions.xlsx)

## [PISA Data - 2018](https://www.oecd.org/pisa/data/2018database/) (> 1GB, Not recommended for Udacity workspace)

- PISA is a survey of students' skills and knowledge as they approach the end of compulsory education. This survey examines
  - how well students have learned the school curriculum,
  - how well-prepared they are for life beyond school.
- Approximately 600,000 students in 79 countries took part in the PISA 2018 assessment of reading, mathematics, and science. See this [data dictionary](https://s3.amazonaws.com/udacity-hosted-downloads/ud507/pisadict2012.csv) to understand the dataset's variables.
- To access the most recent data set (2018), download the files from the website in SPSS format (TXT or CSV formats are unavailable). You may use the pandas function pd.read_spss() to convert it into a usable data frame.
- This data set is large, so you may want to look at a subset of the data.
